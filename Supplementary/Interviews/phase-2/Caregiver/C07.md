# Phase 2 Follow-Up Interview Transcript: Medication Management

**Participant:** Sudarson Saha

---

## 1. Affiliation Ledger & Negotiating Allegiance

**Interviewer:** "You have been using the agent for some weeks now. Tell me how it has gone."

**Sudarson Saha:** "Yeah, I noticed that. Since I am the one mainly handling my grandfather's medicines, I mostly felt like it was helping me to manage his medicines. It was clear enough."

**Interviewer:** "When a dose was due, who did the agent contact, and in what order?"

**Sudarson Saha:** "No, I didn't feel it was getting too involved. Most of the time it was just reminding me about the medicine. That is what I wanted also. If it starts going into other family things, then maybe it would feel different, but for medicine it was okay."

**Interviewer:** "Was there anything it told you that the older adult did not know it had told you?"

**Sudarson Saha:** "Yes, I think when other family members started knowing about the reminders and what was happening. Since three people in the family take medicine, sometimes it is useful if someone else knows what is going on, especially if I am not around. But I would still want to be the main person handling it."

**Interviewer:** "Did the way it worked change at any point during the weeks you used it?"

**Sudarson Saha:** "Together, I would say. It can do the reminder part by itself, but for decisions I would want a person to be involved. Especially with my grandfather, I don't think the system should decide everything on its own."

## 2. Veto Power, Risk, and Silence

**Interviewer:** "Did the agent ever tell you something about the medicines that you knew to be wrong?"

**Sudarson Saha:** "Yes, if I knew there was a reason. I would check the medicine label or prescription information first. If something looks wrong, then yes, I would not just follow the reminder."

**Interviewer:** "Were you able to stop it doing something?"

**Sudarson Saha:** "I think that would be useful, actually. If it is something important, I would rather have it clearly tell me. But it should also tell me why it is giving the warning, not just make a loud alert without explaining."

**Interviewer:** "Did it ever repeat or escalate an alert after you had dealt with it?"

**Sudarson Saha:** "If nobody responds, then maybe it should remind again. Because sometimes I can be busy and miss the first one. If there is still no response, then maybe another family member can be informed. But I would not want it to keep doing that for every small thing."

**Interviewer:** "What happened when nobody answered a reminder?"

**Sudarson Saha:** "The normal thing is just a reminder, I take the medicine and that is it. If there is a missed medicine, repeated missed reminders, or something different from the usual schedule, then I would consider that a problem. It should make that difference clear."

## 3. Care Collectivism & "Checking as Love"

**Interviewer:** "Before the agent, how did you find out whether a dose had been taken? And how do you find out now?"

**Sudarson Saha:** "A little, yes. Earlier I had to remember and remind him myself. Now the reminder can come automatically, so I don't have to keep thinking about the exact time all the time. But I still check with him."

**Interviewer:** "Has anything changed about how often you speak to the older adult about medicines?"

**Sudarson Saha:** "No, I don't think I miss them exactly. The checking is still there. The difference is I don't have to depend only on my memory. So I can spend less time worrying whether I forgot something."

**Interviewer:** "Did the agent's record ever disagree with what someone in the family said had happened?"

**Sudarson Saha:** "I would discuss it. Definitely. The agent can tell me that there is a difference or remind me that something has changed, but if there is a new prescription or a sudden health decision, I would check the doctor's instruction and talk with the family. I wouldn't just change the medicine because the system says so."

**Interviewer:** "Was there a health decision to make while you were using it?"

**Sudarson Saha:** "Yes, exactly. That would be better."

**Sudarson Saha:** "Yes, probably. Even a simple message saying everything is on track would be nice. And if family members notice that also, it gives some encouragement."

**Sudarson Saha:** "For something like medication management, I think sharing basic progress with the family is okay. But I don't think every small detail needs to be shown. Just enough so they know things are being managed."

## 5. Probationary Trust & Retraining

**Interviewer:** "Think back to the first days. What did you do differently then from now?"

**Sudarson Saha:** "Yes, definitely. I wouldn't immediately trust a new system with ten medicines. At first I would compare its reminders with the medicine label and the prescription information. If it keeps giving the correct reminders, then slowly I would trust it more."

**Interviewer:** "Was there a point at which you stopped double-checking it?"

**Sudarson Saha:** "Yes. In the beginning I would check everything myself. After some time, if I saw that the reminders were matching what I already knew, I could depend on them more. But I would still keep the medicine information available."

**Interviewer:** "Do you still keep the schedule in your head?"

**Sudarson Saha:** "Mostly it reduced the need for me to remember every time. I still know the general routine, but now I don't have to keep checking the clock. If the phone or agent reminds me, I can act then. So yes, it takes some pressure away from my memory."

**Interviewer:** "If the agent stopped working tomorrow morning, what would happen?"

**Sudarson Saha:** "Yes, definitely. I would keep them. The reminder is helpful, but the prescription and medicine information are still the main reference."
