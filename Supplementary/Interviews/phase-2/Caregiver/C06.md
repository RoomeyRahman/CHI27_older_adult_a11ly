**Saima Akter Shurmi:** A little, but not in a bad way. Since I am responsible for her medicines, I actually like having that check. It makes me more confident that I have not missed something.

**Interviewer:** What about your grandmother's privacy?

**Saima Akter Shurmi:** Together with the family. The system can remind us, but we still know the actual situation at home. If something changes, we need to check the prescription and understand what happened.

## Veto Power, Risk, and Silence

**Interviewer:** If the system says a medicine has not been given, would you want someone in the family to know?

**Saima Akter Shurmi:** Yes, if it is actually missed. That would be useful. If I am busy and don't notice the reminder, another family member knowing can help.

**Interviewer:** What if the system gives another reminder because you have not responded?

**Saima Akter Shurmi:** That is good. One reminder may not always be enough if I am doing something. A second reminder after some time would be useful.

**Interviewer:** Would you want it to immediately alert the family?

**Saima Akter Shurmi:** No, not immediately. First remind me again. I might have given the medicine but forgotten to confirm it. If there is still no response, then the family can be informed.

**Interviewer:** What if the system says a dose was missed but you know you already gave it?

**Saima Akter Shurmi:** Then I would trust what actually happened. I would not give another dose just because the system says so. I would check the prescription and the routine, and if there is any doubt I would ask someone in the family or the doctor.

**Interviewer:** So would you ever reject what the system tells you?

**Saima Akter Shurmi:** Yes, if I know it is incorrect. The system is a reminder, not the final authority. The doctor's prescription is still the reference.

**Interviewer:** How should the system treat silence?

**Saima Akter Shurmi:** It should not assume immediately that silence means the medicine was missed. It should remind again and give some time. Then, if there is still no confirmation, it can alert the family.

**Interviewer:** What would be a serious failure for you?

**Saima Akter Shurmi:** Giving the wrong medicine or wrong timing would be serious. Also, if it keeps telling the family something was missed when it was actually given, that would become a problem because everyone would start worrying unnecessarily.

**Interviewer:** Has the system changed the normal medicine routine?

**Saima Akter Shurmi:** Not really. The routine is still morning, afternoon, and night. It just makes those timings easier to keep track of.

## Care Collectivism and “Checking as Love”

**Saima Akter Shurmi:** Yes, a little. Before I mainly checked the prescription and remembered the routine myself. Now the reminder helps me check the timing without having to keep thinking about it.

**Interviewer:** Do you miss doing the reminders manually?

**Saima Akter Shurmi:** No, not really. I still check the medicines myself. The system just takes away some of the remembering.

**Interviewer:** If another family member checks whether you gave the medicine, would that bother you?

**Saima Akter Shurmi:** No. It is actually helpful. Everyone in the family cares about her, so checking is normal. I would rather someone ask than find out later that a medicine was missed.

**Interviewer:** Does that kind of checking feel like care?

**Saima Akter Shurmi:** Yes, definitely. Especially with an elderly person, medicine is part of daily care. Asking whether it was given is not really an inconvenience. It is just making sure she is okay.

**Interviewer:** Suppose there is a sudden change in her medicine or the prescription is unclear. What would you do?

**Saima Akter Shurmi:** I would go back to the doctor's prescription. I would not rely only on the system. If the prescription has changed, I would update the routine after checking it properly.

**Interviewer:** Would you discuss that change with the family?

**Saima Akter Shurmi:** Yes. If there is any change, the family should know. Since I am managing the medicines, I would tell them what has changed.

**Interviewer:** Would you allow the system to decide that a new medicine should be given?

**Saima Akter Shurmi:** No. No, it should not decide that. It can remind us about what the doctor has prescribed. A new medicine needs to be checked first.

**Interviewer:** Did the system replace your memory?

**Saima Akter Shurmi:** No. I still know the routine. But instead of keeping all the times in my head, the phone is also keeping track. So it reduces the mental load.

**Interviewer:** Did it change your sense of the medicine timing?

## Closing and Plural Principal

**Interviewer:** Finally, who do you think the system ultimately works for?

**Saima Akter Shurmi:** Both. It helps my grandmother get her medicines on time, and it helps me manage the responsibility. So I don't see it as only for one person.

**Interviewer:** When would it be acceptable for the system to become a family advocate?

**Saima Akter Shurmi:** If there is a genuine missed medicine and I have not responded, then it is useful for the family to know. That is when it should involve someone else.

**Interviewer:** Should it contact the family immediately?

**Saima Akter Shurmi:** No. First give me the reminder. Maybe repeat it once. If I still don't respond, then notify the family. Otherwise it can create unnecessary concern.

**Interviewer:** What was the most useful part of the system for you?

**Saima Akter Shurmi:** The timing reminder. I already use phone alarms, so this fits naturally into how I manage things. I don't have to stop what I am doing just to remember the next medicine time.

**Interviewer:** Would you still prefer an alarm or call?

**Saima Akter Shurmi:** I think both can work, but a clear sound is important. If I am busy, I need something that gets my attention.

**Interviewer:** Would a text message be useful?

**Saima Akter Shurmi:** It can be useful for information, but for the actual medicine timing I prefer sound or a call. I notice those faster.

**Interviewer:** What about medicine stock or refill reminders?

**Saima Akter Shurmi:** That would be useful. If there are five or six medicines, it is easy to notice one is finishing only at the last moment. A reminder before it runs out would help.

**Interviewer:** Should the refill reminder go to you or another family member?

**Saima Akter Shurmi:** It could go to me first. If I don't act on it, then another family member can know. That would make things easier.

**Interviewer:** What about doctor appointment reminders?

**Saima Akter Shurmi:** Yes, that could be useful too. But I would not want too many notifications. The important things should stand out.

**Interviewer:** Would you want the system to show information about each medicine?

**Saima Akter Shurmi:** Basic information, yes. Medicine name, time, dosage, maybe a picture. That would make it easier to confirm that the right medicine is being given.

**Interviewer:** What if the system could recognise the medicine from a photo?

**Saima Akter Shurmi:** That could be helpful, especially when there are several medicines. But I would still verify it against the prescription. I would not depend completely on automatic recognition.

**Interviewer:** Would you trust the system more if it was set up using the doctor's prescription?

**Saima Akter Shurmi:** Yes, definitely. The prescription should be the main source. If the system is based on that, then I feel more confident using it.

**Interviewer:** What if other family members also started using the same system?

**Saima Akter Shurmi:** That would be helpful. Then everyone understands the routine and someone else can notice if there is a problem.

**Saima Akter Shurmi:** No, not really. That could create confusion. Other people's medicines are not necessarily suitable for my grandmother.
