## 7. Follow-up Reflection from the Caregiver's Perspective

**Interviewer:** "I just have a few more questions. From your side as the person who usually checks the medicines, how is this smart reminder different from a normal phone alarm?"

**Juthi Rani Bhowmik:** "A normal alarm only rings. This one can do a little more. It can remind them which medicine to take, and if they still do not respond after some time, then it can tell me. That is more useful because I am not always at home."

**Interviewer:** "So what should it do that a normal alarm cannot do?"

**Juthi Rani Bhowmik:** "First it should remind the older person clearly. Maybe voice is better. Then if there is still no response, it can inform me. But it should not immediately make it look like something serious happened."

**Interviewer:** "Why is that important for you?"

**Juthi Rani Bhowmik:** "Because sometimes they may already have taken the medicine and just forgot to press something. If every missed confirmation comes to me as an emergency, then I will worry and I will also stop trusting the alerts."

**Interviewer:** "How can this system make things easier for you as a caregiver?"

**Juthi Rani Bhowmik:** "The main thing is I don't have to remember every medicine time myself. Before, if I was at work or outside, I would call and ask. If the system reminds them first, then I only need to check when something is actually missed."

**Interviewer:** "What kind of things would you want the system to inform you about?"

**Juthi Rani Bhowmik:** "Repeated missed medicine, no response for some time, medicine finishing, or maybe if there is some mismatch with the normal schedule. Those are useful. I don't need a message every time they take a tablet."

**Interviewer:** "Would that reduce some pressure on you?"

**Juthi Rani Bhowmik:** "Yes, definitely. Caregiving is not only medicine. I also have my own work and other family things. So if the system can handle the routine reminder, it takes away one small thing I have to keep in my head all day."

**Interviewer:** "Do you think this system can solve all the problems you face when managing their medicines?"

**Juthi Rani Bhowmik:** "No, not all. It can help with timing and reminders. But it cannot understand every situation by itself. If the doctor changes a medicine, if there is a side effect, or if the prescription is unclear, then we still have to check properly."

**Interviewer:** "What would you still need to do yourself?"

**Juthi Rani Bhowmik:** "I would still check the prescription, make sure the medicine information is correct, update changes, and talk to the doctor if something is unusual. I would not leave those things completely to the system."

**Interviewer:** "If the system says one thing but the prescription says something different, what would you trust?"

**Juthi Rani Bhowmik:** "The prescription and the doctor. I would stop and check. The system is useful only if the information inside it is correct."

**Interviewer:** "Is there anything the system should never decide by itself?"

**Juthi Rani Bhowmik:** "Yes. It should not change a medicine, increase or decrease a dose, or tell someone to stop a medicine by itself. Those are medical decisions."

**Interviewer:** "Then what should the actual role of the system be for the older adult?"

**Juthi Rani Bhowmik:** "For them, it should be very simple. Remind them, tell them which medicine and when, maybe by voice, and let them confirm easily."

**Interviewer:** "And what should its role be for you as the caregiver?"

**Juthi Rani Bhowmik:** "For me, it should give me useful information only when I need to step in. I should be able to check the schedule, update it when the doctor changes something, and know if there is a real missed dose."

**Interviewer:** "So you would not want to monitor every small action?"

**Juthi Rani Bhowmik:** "No. That is not necessary. They should still have some independence. I only need to know when there is something I should actually do."

**Interviewer:** "What should the family still do even if the system works well?"

**Juthi Rani Bhowmik:** "We still need to talk to them, check how they are feeling, bring the medicines, and help with changes. A reminder cannot replace that."

**Interviewer:** "And what should the doctor still do?"

**Juthi Rani Bhowmik:** "The doctor should make the medical decisions. The system should help us follow those decisions, not make new ones."

**Interviewer:** "If you had to describe the system's main role in one sentence, what would you say?"

**Juthi Rani Bhowmik:** "It should handle the routine reminders and tell me when there is a real problem, so I don't have to check everything all the time."

**Interviewer:** "Anything else you would want to change?"

**Juthi Rani Bhowmik:** "Keep it simple and reliable. The alerts should be meaningful. If it gives too many unnecessary warnings, then both the older person and the caregiver will get tired of it."

**Interviewer:** "Thank you for your time."

**Juthi Rani Bhowmik:** "Thank you."
