# Medical App Feature Report

## 1. Features Requested by the Majority

Based on the recurring requirements in the original medication-management interviews, the following features were consistently requested. One-off or minority requests have been excluded.

- **Medicine reminders** — remind the user when a medicine is due.
- **Clear medicine details in the reminder** — show or state the medicine name and timing, including before/after food where applicable.
- **Phone notifications** — provide a clear notification so the user does not have to remember the schedule manually.
- **Family notification for missed medicine** — allow a family member/caregiver to know when a medicine has been missed.
- **Simple and easy interface** — avoid unnecessary screens, buttons, typing, or complex functions.
- **Readable information** — medicine information should be clear and easy to understand.
- **Community-based support** — provide a simple community space where users can share medication experiences, encouragement, or general reminders with others. This is supported by **3 participants** who described community/friend influence on medication-related decisions or routines. The feature should not provide or encourage unsupervised medicine recommendations.

## 2. Features Already Built

The current application includes:

- **Medicine CRUD**
  - Add/set up medicines.
  - Edit medicine details.
  - Manage the stored medicine information.

- **Push notifications**
  - Sends a notification to the phone when a medicine is scheduled.

- **Medication statistics**
  - **Streaks** showing continuous medication-taking periods.
  - **Logbook** showing medication records.
  - **Daily heat map** in a GitHub-style format showing whether medicine was taken on each day.

## Summary

The current application covers the main recurring requirements identified in the interviews: **medicine setup, clear medication scheduling, reminders, and medication history/progress tracking**.

Family and community missed-dose notification was a recurring requirement in the interviews but is **not listed as an implemented feature**
