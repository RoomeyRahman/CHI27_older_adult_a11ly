# Cross-phase affiliation synthesis: six-column matrix (25 retained affiliation codes)

Each row pairs a Phase 1 human-to-human form with a Phase 2 agent-directed form. The code cell names the Phase 1 and Phase 2 master codes it draws on; the example cell carries one Phase 1 and one Phase 2 extract, each verbatim from the master matrices. Practice is filled only where one of the five affiliation practices fits; the rows without one are conditions and outcomes carried for completeness of the symmetry.
