# P09, Phase 1: Pass B code register

## Trim rationale

Candidates after Pass A: 29. After reconciliation (6 merges): 23. Retained: 20. Parked: 3.

The retained count is below the 25 to 30 target because the transcript is short and structured by six compound questions; padding it to 25 would require splitting codes that name one mechanism. Twenty is the honest number. Parking fell on inventory (device, staying at home) and on the closing blessing, whose register is carried in the memo.

Hardest calls. (1) `Kin address between parties`: the interview is conducted as between a young relative and an aunt, which conditions everything she says; but it is an interactional artifact, not a code about medication work. Parked, recorded in the memo. (2) `'what suggestions can an uneducated village woman give' [tr]`: could be read as courtesy and parked; retained, because it is the account's clearest statement of the position from which she speaks about design, and because parking it would remove a participant's refusal of the design role the interview offered. (3) `Takes when remembered or skips`: a single line, but it is the only recovery rule in the phase so far that involves no consultation, and it cuts against the pattern.
